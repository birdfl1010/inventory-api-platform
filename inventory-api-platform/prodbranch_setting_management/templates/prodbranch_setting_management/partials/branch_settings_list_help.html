Help Page

This page provides an overview of stock settings by branch and the associated costs of manual setting overrides. Use it to quickly understand and manage your configurations.

How to navigate:

  • Entries per page: Adjust the number of items displayed using the dropdown at the top left of the table.
  • Pagination: Move between pages using the controls at the bottom right.
  • Search: Locate specific values using the search bar in the top right corner.
  • Sorting: Click on column headers to sort the table by that column.
  • Edit settings: Use the "Edit" button in each row to navigate to the settings modification page.
